
# Expense Tracker

Expense Tracker is a full-stack web application for managing personal expenses.
Users can add, view, edit, delete, and filter expenses, with all data stored in a PostgreSQL database.

## How to run

### Backend

1. Open the `backend` folder in the terminal.

2. Install the required dependencies:

```bash
npm install

3. Create a PostgreSQL database named:

expense_tracker

4. Run the schema. sql file on the expense_tracker database.
5. Create a .env file inside the backend folder.
6. Add your PostgreSQL connection information:

DB_HOST=localhost
DB_PORT=5432
DB_USER=your_username
DB_PASSWORD=your_password
DB_NAME=expense_tracker

7. Start the backend server:

</> Bash

8. The backend will run on:

http://localhost:3000

Frontend

1. Open the frontend folder in VS Code.
2. Open index.html using Live Server.
3. Make sure the backend server is running before using the application.

Features

Add an expense (with validation)
Delete an expense
Edit an expense
Filter by category
Summary cards (total, count, highest)
Data is saved in a PostgreSQL database
